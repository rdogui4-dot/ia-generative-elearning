## Bienvenue

### Pour qui est ce livre ?

Ce livre est fait pour vous si vous êtes **débutant(e)** : vous avez entendu parler de ChatGPT, de « l'intelligence artificielle » ou de l'IA, mais vous ne savez pas exactement de quoi il s'agit, ni comment vous en servir. Aucune connaissance technique n'est nécessaire. Il suffit de savoir utiliser un téléphone ou un ordinateur.

Que vous soyez commerçant(e), étudiant(e), enseignant(e), agriculteur(trice), employé(e) de bureau, entrepreneur(e) ou simplement curieux(se), à Abidjan, Dakar, Douala, Kinshasa, Nairobi, Lagos, Kigali ou ailleurs en Afrique, vous trouverez ici des explications simples et des exemples proches de votre vie.

### Ce que vous saurez faire à la fin

1. Expliquer avec vos mots ce qu'est l'IA générative.
2. Utiliser un assistant IA pour vous aider dans votre travail ou vos études.
3. Écrire des instructions claires pour obtenir de bonnes réponses.
4. Reconnaître les erreurs et les pièges de l'IA.
5. Protéger vos données personnelles.
6. Comprendre pourquoi l'IA est un enjeu pour l'Afrique et ses langues.
7. Vous faire un plan d'action personnel de 30 jours.

### Comment utiliser ce livre

- Chaque chapitre commence par **ce que vous allez apprendre** et finit par un **résumé** et un petit quiz **« Testez-vous »**.
- Les encadrés vous aident : **À retenir**, **Astuce**, **Attention**, **Exemple africain**.
- Essayez chaque exemple avec un vrai outil. On apprend en pratiquant.
- Avancez à votre rythme : un chapitre par jour ou par semaine, comme vous voulez.

> **Astuce** Vous n'avez pas besoin d'un abonnement payant pour suivre ce livre. Plusieurs assistants IA proposent une version gratuite, souvent suffisante pour débuter. Les offres changent : vérifiez-les avant de choisir.

> **Attention** Le domaine de l'IA évolue très vite. Les idées de ce livre restent valables longtemps, mais les noms d'outils, les prix et les fonctionnalités peuvent changer. Vérifiez toujours les informations récentes.

## Chapitre 1 : C'est quoi, l'IA générative ?

### Ce que vous allez apprendre

- Ce que veut dire « intelligence artificielle ».
- Ce que « générative » ajoute.
- Où vous rencontrez déjà l'IA sans le savoir.

### 1.1 L'intelligence artificielle, en simple

L'**intelligence artificielle (IA)**, c'est l'ensemble des techniques qui permettent à une machine d'accomplir des tâches qui demandent normalement de l'intelligence humaine : reconnaître un visage sur une photo, comprendre une voix, traduire une phrase, conseiller un itinéraire.

Une machine classique suit des ordres précis écrits par un programmeur. Une machine « intelligente » **apprend à partir d'exemples**. C'est comme un enfant : on ne lui explique pas toutes les règles du langage, il apprend en écoutant beaucoup de personnes parler.

### 1.2 Et « générative » ?

Le mot **générer** veut dire **créer**. Une IA générative est une IA qui **produit quelque chose de nouveau** : un texte, une image, une voix, une musique, une vidéo, un programme informatique.

Imaginez deux employés dans une coopérative de cacao.

- Le premier **trie** : devant chaque fève, il dit « bonne » ou « mauvaise ». Il classe ce qui existe déjà.
- Le second **rédige** : à partir de quelques notes, il écrit un rapport complet pour les acheteurs. Il crée quelque chose qui n'existait pas.

Le premier ressemble à l'IA « classique ». Le second ressemble à l'**IA générative**.

### 1.3 Les poupées russes de l'IA

Voici comment les mots s'emboîtent :

```
+-------------------------------------------------+
| INTELLIGENCE ARTIFICIELLE                       |
| (machines qui font des tâches "intelligentes")  |
|                                                 |
|  +-------------------------------------------+  |
|  | APPRENTISSAGE AUTOMATIQUE                 |  |
|  | (la machine apprend avec des exemples)    |  |
|  |                                           |  |
|  |  +-------------------------------------+  |  |
|  |  | IA GÉNÉRATIVE                       |  |  |
|  |  | (elle crée du texte, des images...) |  |  |
|  |  +-------------------------------------+  |  |
|  +-------------------------------------------+  |
+-------------------------------------------------+
```

### 1.4 Vous utilisez déjà l'IA

Sans le savoir, vous rencontrez l'IA tous les jours :

- Le **clavier de votre téléphone** qui propose le mot suivant.
- Les **recommandations de vidéos** sur YouTube, TikTok ou Facebook.
- La **reconnaissance vocale** quand vous dictez un message WhatsApp.
- La **détection de fraude** de votre opérateur de mobile money ou de votre banque.
- Les **filtres photo** de votre téléphone.
- Les **traductions automatiques**.

Depuis novembre 2022, avec le lancement public de ChatGPT, l'IA générative est devenue accessible à tout le monde : n'importe qui peut « discuter » avec une machine et lui demander de rédiger, expliquer, résumer ou traduire.

> **Exemple africain** Une vendeuse de tissus à Bouaké écrit à un assistant IA : « Aide-moi à écrire un message pour annoncer mes nouveaux pagnes à mes clientes sur WhatsApp. » En quelques secondes, elle obtient trois versions parmi lesquelles choisir. Elle garde celle qu'elle préfère et l'adapte avec ses propres mots.

### 1.5 Ce que l'IA générative peut créer

| Type | Exemples |
|---|---|
| **Texte** | Lettres, messages, résumés, explications, traductions, idées |
| **Image** | Affiches, illustrations, logos, décors |
| **Son** | Voix de synthèse, transcription, musique |
| **Vidéo** | Courts clips, animations |
| **Code** | Petits programmes, formules de tableur |

### Résumé du chapitre 1

- L'IA est une machine qui apprend à partir d'exemples.
- L'IA générative **crée** du contenu nouveau : texte, image, son, vidéo, code.
- Vous en utilisez déjà des formes dans votre quotidien.

### Testez-vous

**Q1. Que fait une IA générative ?**

a) Elle trie uniquement des données ; b) Elle produit du contenu nouveau ; c) Elle répare les téléphones ; d) Elle remplace Internet.

**Réponse : b.** Le mot « générative » vient de « générer », c'est-à-dire créer.

**Q2. Lequel de ces exemples est une IA que vous utilisez déjà ?**

a) Le clavier du téléphone qui suggère des mots ; b) Une calculatrice basique ; c) Une lampe torche ; d) Un ventilateur.

**Réponse : a.** Le clavier prédictif apprend des habitudes d'écriture.

**Q3. Comment une IA « apprend »-elle ?**

a) En recevant des ordres précis pour chaque situation ; b) À partir de nombreux exemples ; c) En dormant ; d) En copiant votre téléphone.

**Réponse : b.** Elle repère des régularités dans une grande quantité d'exemples.

## Chapitre 2 : Comment ça marche ? (sans jargon)

### Ce que vous allez apprendre

- L'idée centrale : prédire la suite.
- Ce qu'est un « token » et pourquoi c'est important.
- Comment un assistant est fabriqué, avec une comparaison simple.

### 2.1 L'idée centrale : deviner la suite

Complétez cette phrase : « Bonjour, je voudrais acheter du crédit de ... »

Vous avez pensé « communication », ou « téléphone ». Pourquoi ? Parce que vous avez déjà entendu cette phrase souvent.

Les assistants IA qui écrivent du texte, appelés **modèles de langage** (ou **LLM**, pour *Large Language Model*), font **exactement cela**, mais à très grande échelle : ils ont « lu » des milliards de textes et savent très bien deviner quel est le morceau de texte le plus probable après ceux qui précèdent. Ils écrivent une réponse **morceau par morceau**, en devinant chaque fois la suite.

```
"Le marché de Treichville est ..."
        |
        v
Le modèle calcule des chances :
   "animé"    -> forte chance
   "célèbre"  -> chance moyenne
   "fermé"    -> faible chance
        |
        v
Il choisit un mot, puis recommence pour le suivant
```

> **À retenir** Un assistant IA ne « cherche » pas la vérité dans une encyclopédie : il **fabrique la suite la plus vraisemblable**. C'est pour cela qu'il écrit très bien, mais qu'il peut aussi se tromper.

### 2.2 Les tokens : les petits morceaux de texte

Le modèle ne lit pas exactement des mots. Il découpe le texte en petits morceaux appelés **tokens** : parfois un mot entier, parfois un morceau de mot, parfois un signe de ponctuation.

Pourquoi est-ce utile de le savoir ?

- Les services payants comptent souvent en tokens.
- Chaque conversation a une limite de tokens : c'est la **mémoire de travail** de l'assistant. Dans une très longue discussion, il peut oublier le début.
- Les langues très présentes dans les données d'entraînement, comme l'anglais et le français, sont découpées de façon efficace. Beaucoup de langues africaines sont découpées en **plus de morceaux**, ce qui peut coûter plus cher et donner des résultats moins bons.

### 2.3 Comment fabrique-t-on un assistant ? Une comparaison avec un apprenti

Imaginez qu'on forme un apprenti secrétaire.

```
ÉTAPE 1 : Il lit énormément de livres, journaux et documents.
   (le "pré-entraînement" : la machine lit des milliards de textes)
        |
        v
ÉTAPE 2 : Un formateur lui montre des exemples de bonnes réponses
   à des demandes précises.
   (l'"affinage" : on apprend à suivre les consignes)
        |
        v
ÉTAPE 3 : Des personnes évaluent ses réponses et le corrigent :
   "ceci est poli", "ceci est dangereux".
   (l'"alignement" : on le rend utile et sûr)
```

Le résultat est un assistant qui sait beaucoup de choses, mais qui n'a jamais vécu dans votre quartier, n'a jamais vendu au marché, ni cultivé un champ.

> **Attention** Les personnes qui corrigent et évaluent ces modèles ne représentent pas toutes les cultures. C'est une des raisons pour lesquelles les réponses reflètent parfois mal les réalités africaines.

### 2.4 Et les images ?

Les générateurs d'images fonctionnent autrement, souvent par un procédé appelé **diffusion**. On apprend à la machine à partir d'images à qui l'on ajoute progressivement du « bruit » (comme la neige d'une vieille télévision). Elle apprend ensuite à faire l'inverse : à partir de bruit, **retrouver une image**, guidée par votre description écrite.

### 2.5 Pourquoi la même question donne parfois des réponses différentes ?

Parce qu'il y a une part de **hasard** dans le choix du morceau suivant, réglée par un paramètre appelé **température**. Une température basse donne des réponses plus stables ; une température haute, des réponses plus variées et plus créatives. C'est normal : demandez deux fois « propose-moi un slogan » et vous aurez deux slogans différents.

### Résumé du chapitre 2

- Un assistant IA devine la suite du texte, morceau par morceau.
- Ces morceaux s'appellent des tokens ; les langues africaines sont souvent défavorisées.
- Il est fabriqué en trois étapes : lecture massive, apprentissage des consignes, correction.
- Il peut se tromper, et ses réponses varient d'une fois à l'autre.

### Testez-vous

**Q1. Comment un assistant IA produit-il sa réponse ?**

a) Il la copie sur Internet ; b) Il devine la suite la plus vraisemblable, morceau par morceau ; c) Il appelle un humain ; d) Il la tire au sort sans logique.

**Réponse : b.** Il génère le texte à partir de probabilités apprises.

**Q2. Un token est :**

a) Un mot de passe ; b) Un petit morceau de texte ; c) Une image ; d) Un abonnement.

**Réponse : b.** Un token peut être un mot, un morceau de mot ou un signe.

**Q3. Pourquoi deux réponses à la même question peuvent-elles être différentes ?**

a) À cause d'une panne ; b) Parce qu'il y a une part de hasard dans la génération ; c) Parce que l'assistant est fâché ; d) Parce que la question a changé.

**Réponse : b.** La température règle ce degré de hasard.

## Chapitre 3 : Ce que l'IA générative sait faire

### Ce que vous allez apprendre

- Les grandes familles d'outils.
- Comment choisir un outil selon vos besoins.
- Comment économiser vos données mobiles.

### 3.1 Les grandes familles d'outils

| Famille | Ce qu'elle fait | Exemple d'usage en Afrique |
|---|---|---|
| **Assistants de texte** | Écrivent, résument, expliquent, traduisent | Rédiger une lettre, préparer un cours, répondre à un client |
| **Générateurs d'images** | Créent des images à partir d'une description | Faire une affiche pour un événement ou une boutique |
| **Outils de voix** | Transcrivent une voix en texte ou lisent un texte à voix haute | Noter une réunion, faire un message vocal |
| **Générateurs de vidéo** | Créent de courts clips | Faire une publicité simple |
| **Aide à la programmation** | Écrit ou explique du code | Créer un petit site ou un tableur automatisé |
| **Outils multimodaux** | Combinent texte, image et voix | Photographier une facture et demander un résumé |

### 3.2 Modèles fermés et modèles ouverts

- Un modèle **fermé (propriétaire)** s'utilise sur le site ou l'application de son fournisseur. C'est simple, mais vos textes partent vers les serveurs de l'entreprise.
- Un modèle **ouvert** peut être téléchargé et installé par une organisation sur ses propres machines. C'est plus technique, mais cela donne plus de contrôle sur les données.

Pour débuter, vous utiliserez presque toujours un assistant en ligne ou une application mobile.

### 3.3 Comment choisir un outil ?

Posez-vous ces sept questions :

1. Est-ce **gratuit** ou payant ? Combien en monnaie locale, avec les frais de paiement ?
2. Comprend-il bien **mon français** (ou ma langue) ?
3. Est-il **disponible dans mon pays** et puis-je payer avec un moyen accessible ?
4. Consomme-t-il **beaucoup de données** mobiles ?
5. Que fait-il de **mes données** ? Peut-on refuser qu'elles servent à l'entraîner ?
6. Est-il **facile à utiliser** sur mon téléphone ?
7. Puis-je **tester gratuitement** avant de m'engager ?

### 3.4 Utiliser l'IA quand la connexion est chère ou instable

Beaucoup d'Africains ont une connexion mobile coûteuse ou irrégulière. Quelques astuces :

- **Préparez votre message avant de vous connecter** : écrivez vos instructions complètes dans vos notes, puis collez-les d'un seul coup.
- **Regroupez plusieurs demandes** dans un seul message quand c'est possible.
- **Privilégiez le texte** : les images et vidéos consomment beaucoup plus de données.
- **Utilisez le wifi** d'un lieu public, du bureau ou d'un cybercafé quand vous le pouvez.
- **Partagez** : un groupe d'amis ou de collègues peut apprendre ensemble et s'entraider.

> **Exemple africain** Un étudiant de Kinshasa prépare sa question complète dans ses notes hors ligne, puis se connecte quelques minutes pour l'envoyer et copier la réponse. Il l'étudie ensuite tranquillement, sans consommer de données.

### Résumé du chapitre 3

- Il existe des outils pour le texte, l'image, la voix, la vidéo et le code.
- Choisissez selon le coût, la langue, la confidentialité et la facilité d'usage.
- On peut utiliser l'IA malgré une connexion limitée en s'organisant bien.

### Testez-vous

**Q1. Quel outil convient pour créer une affiche ?**

a) Un générateur d'images ; b) Un traitement vocal ; c) Une calculatrice ; d) Un GPS.

**Réponse : a.** Les générateurs d'images créent des visuels à partir d'une description.

**Q2. Quelle astuce aide à économiser des données mobiles ?**

a) Envoyer dix petits messages ; b) Préparer sa demande hors ligne puis l'envoyer d'un coup ; c) Demander des vidéos en haute qualité ; d) Laisser tourner l'application toute la journée.

**Réponse : b.** Préparer d'abord votre message limite la consommation.

**Q3. Un modèle « ouvert » permet surtout :**

a) D'être installé et contrôlé par l'organisation qui l'utilise ; b) D'être toujours gratuit ; c) De ne jamais se tromper ; d) De fonctionner sans électricité.

**Réponse : a.** Il peut être téléchargé, ce qui donne plus de contrôle sur les données.

## Chapitre 4 : Mes premiers pas avec un assistant IA

### Ce que vous allez apprendre

- Comment démarrer une première conversation.
- Les bons réflexes dès le début.
- Comment poursuivre et corriger une réponse.

### 4.1 Se lancer

1. **Choisissez un assistant** (voir chapitre 3) et ouvrez-le sur votre téléphone ou votre ordinateur.
2. **Créez un compte** si nécessaire, avec une adresse e-mail que vous contrôlez, et un mot de passe solide.
3. **Repérez la zone de saisie** : c'est là que vous écrivez votre message, appelé **prompt** (instruction).
4. **Écrivez comme si vous parliez à un collègue compétent** : phrases complètes, claires, polies si vous voulez.
5. **Lisez la réponse** avec un regard critique.
6. **Poursuivez la conversation** pour améliorer le résultat.

### 4.2 Un premier exercice simple

Écrivez :

```
Explique-moi en 5 phrases simples ce qu'est l'intelligence
artificielle, comme si je n'avais jamais entendu ce mot.
Donne un exemple tiré de la vie quotidienne en Afrique de l'Ouest.
```

Puis posez des questions de suivi :

- « Peux-tu réexpliquer plus simplement ? »
- « Donne-moi un autre exemple. »
- « Résume en une seule phrase. »

Vous venez d'avoir votre première **conversation** avec une IA. L'assistant se souvient de ce que vous avez dit **dans cette conversation** (dans la limite de sa mémoire de travail), ce qui permet de préciser et corriger en cours de route.

### 4.3 Les cinq bons réflexes

1. **Soyez précis.** Plus votre demande est claire, meilleure est la réponse.
2. **Donnez du contexte.** Qui êtes-vous ? Pour qui écrivez-vous ? Dans quel pays ?
3. **Demandez un format.** Liste, tableau, message court, lettre formelle.
4. **Recommencez.** Le premier résultat est un brouillon, pas un produit fini.
5. **Vérifiez.** Vous restez responsable de ce que vous utilisez.

### 4.4 Corriger ou améliorer une réponse

Vous pouvez répondre à l'assistant avec des consignes de correction :

| Ce que vous voulez | Ce que vous écrivez |
|---|---|
| Plus court | « Résume en 3 lignes. » |
| Plus simple | « Explique avec des mots plus simples. » |
| Plus chaleureux | « Rends le ton plus amical. » |
| Plus formel | « Rends-le plus professionnel. » |
| Plus concret | « Ajoute un exemple ivoirien (ou sénégalais, camerounais...). » |
| Autre version | « Propose une autre version, différente. » |

### 4.5 Conversation ou nouvelle conversation ?

- Pour un **même sujet**, poursuivez la même conversation.
- Pour un **sujet différent**, ouvrez une nouvelle conversation : cela évite les mélanges.
- Si une conversation devient très longue et que l'assistant semble « perdre le fil », résumez les points importants dans un nouveau message ou ouvrez une nouvelle conversation.

### 4.6 Ce qu'il ne faut pas faire au début

- Ne collez **jamais** de données confidentielles (mots de passe, numéros de carte, dossiers de patients, documents d'identité).
- Ne prenez pas la première réponse pour une vérité absolue.
- N'utilisez pas l'IA pour tricher à un examen : elle doit vous aider à **apprendre**, pas à éviter d'apprendre.

### Résumé du chapitre 4

- Ouvrez un assistant, écrivez clairement, lisez, puis améliorez par de petits messages de suivi.
- Cinq réflexes : précision, contexte, format, itération, vérification.
- Restez prudent avec vos données et responsable de vos résultats.

### Testez-vous

**Q1. Le premier résultat d'un assistant est :**

a) Toujours parfait ; b) Un brouillon que l'on peut améliorer ; c) Toujours faux ; d) Impossible à modifier.

**Réponse : b.** On peut demander de raccourcir, simplifier, changer le ton, etc.

**Q2. Que ne faut-il jamais coller dans un assistant grand public ?**

a) Une recette de cuisine ; b) Un mot de passe ou un numéro de carte bancaire ; c) Une question de culture générale ; d) Un titre d'article.

**Réponse : b.** Ce sont des données sensibles.

**Q3. Vous changez complètement de sujet. Que faire ?**

a) Continuer dans la même conversation ; b) Ouvrir une nouvelle conversation ; c) Éteindre le téléphone ; d) Supprimer l'application.

**Réponse : b.** Une nouvelle conversation évite les mélanges.

## Chapitre 5 : Bien écrire ses instructions (les « prompts »)

### Ce que vous allez apprendre

- Pourquoi la qualité de votre demande change tout.
- Une méthode simple en quatre lettres : R-C-T-F.
- Comment adapter vos demandes au contexte africain.

### 5.1 Pourquoi c'est important ?

Un assistant IA ne devine pas vos pensées. Il répond à **ce que vous écrivez**, et à rien d'autre. Comparez :

| Demande floue | Demande claire |
|---|---|
| « Parle-moi de la vente. » | « Je tiens une boutique de vêtements à Bouaké. Donne-moi 5 idées simples pour vendre plus grâce à WhatsApp, avec un petit budget de 20 000 FCFA par mois. Présente-les sous forme de liste. » |

La deuxième demande donne des réponses **utiles et adaptées**.

### 5.2 La méthode R-C-T-F

| Lettre | Signification | Question à se poser | Exemple |
|---|---|---|---|
| **R** | Rôle | Qui doit-il être ? | « Tu es conseiller pour petits commerçants. » |
| **C** | Contexte | Que doit-il savoir sur moi et ma situation ? | « J'ai une épicerie à Kumasi avec 2 employés. » |
| **T** | Tâche | Que veux-je obtenir précisément ? | « Explique comment suivre mes stocks avec un cahier. » |
| **F** | Format | Sous quelle forme ? | « En 6 étapes courtes, avec des mots simples. » |

Vous pouvez y ajouter des **contraintes** : longueur, ton, public, langue.

**Exemple complet :**

```
Tu es conseiller pour petits commerçants. (Rôle)
J'ai une petite épicerie à Kumasi, 2 employés, je note tout
dans un cahier. (Contexte)
Explique-moi comment suivre mes stocks pour ne jamais tomber
en rupture. (Tâche)
Réponds en 6 étapes courtes avec des mots simples. (Format)
```

> **Astuce** Ajoutez : « Si tu as besoin de plus d'informations, pose-moi d'abord des questions. » L'assistant vous aidera à préciser votre besoin.

### 5.3 Trois techniques faciles

**a) Donner un exemple.** Montrez ce que vous voulez.

```
Écris des réponses courtes et polies aux clients.
Exemple : Client : "Ma commande est en retard !"
Réponse : "Bonjour, nous sommes désolés pour ce retard. Pouvez-vous
nous donner votre numéro de commande pour vérifier ?"
Maintenant, réponds à : "Je n'ai pas reçu mon remboursement."
```

**b) Demander de réfléchir étape par étape.** Pour un calcul ou une décision : « Explique ton raisonnement étape par étape. »

**c) Fournir la matière.** Au lieu de « Résume le rapport », collez le texte et écrivez : « Résume uniquement à partir du texte ci-dessus. Si une information n'y est pas, dis-le. »

### 5.4 Adapter ses demandes au contexte africain

Les assistants ont été formés avec beaucoup de contenus venus d'ailleurs. Précisez donc **votre réalité** :

- **Le pays et la ville** (les prix, les lois et les usages diffèrent).
- **La monnaie** (FCFA, naira, cedi, shilling, rand, dirham...).
- **Vos contraintes** : coupures d'électricité, connexion instable, paiement par mobile money, importance de WhatsApp.
- **Le niveau de langage** : simple, formel, pour des élèves, pour des clients.

**Exemple :**

```
Tu es formateur en gestion pour jeunes entrepreneurs.
Je gère un petit maquis à Yopougon (10 employés). Je reçois des
paiements en espèces, Orange Money et Wave. L'électricité est
souvent coupée.
Propose-moi une méthode simple pour suivre mes recettes et
dépenses chaque jour, sans logiciel payant.
Format : 7 étapes numérotées, langage simple.
```

### 5.5 Utiliser une langue africaine

Les assistants sont souvent moins bons dans les langues africaines que dans les grandes langues internationales. Quelques conseils :

1. **Testez** : demandez une traduction, puis demandez de la retraduire en français pour comparer.
2. **Écrivez simplement** : phrases courtes, mots courants.
3. **Faites relire** par une personne qui parle la langue avant de diffuser un message important (santé, éducation, contrat).
4. **Donnez un mini-glossaire** : « Utilise ces mots : ... ».

> **Attention** Pour un message de santé, de sécurité ou juridique, ne diffusez jamais une traduction automatique sans relecture par une personne compétente.

### Résumé du chapitre 5

- La qualité de la demande détermine la qualité de la réponse.
- R-C-T-F : Rôle, Contexte, Tâche, Format.
- Précisez toujours votre pays, votre monnaie et vos contraintes locales.
- Pour les langues africaines : testez, simplifiez, faites relire.

### Testez-vous

**Q1. Que signifie la lettre C dans R-C-T-F ?**

a) Correction ; b) Contexte ; c) Code ; d) Copie.

**Réponse : b.** Le contexte explique votre situation à l'assistant.

**Q2. Quelle demande est la meilleure ?**

a) « Parle de marketing. » ; b) « Donne-moi 5 idées de publicités WhatsApp pour ma boutique de chaussures à Douala, budget 15 000 FCFA, en liste. » ; c) « Aide-moi. » ; d) « Fais quelque chose. »

**Réponse : b.** Elle contient un contexte, un budget et un format.

**Q3. Avant de diffuser une traduction en langue locale sur un sujet de santé, il faut :**

a) La diffuser immédiatement ; b) La faire relire par une personne qui parle bien cette langue ; c) La traduire encore trois fois ; d) La supprimer.

**Réponse : b.** Une erreur de traduction peut avoir des conséquences graves.

## Chapitre 6 : Les limites et les pièges de l'IA

### Ce que vous allez apprendre

- Ce qu'est une « hallucination ».
- Pourquoi l'IA peut être partiale.
- Comment vérifier une réponse.
- Comment reconnaître les arnaques et les faux contenus.

### 6.1 Les hallucinations

Une **hallucination**, c'est quand l'IA donne une réponse **fausse mais présentée avec assurance** : un chiffre inventé, une loi qui n'existe pas, une source qu'on ne trouve nulle part.

**Pourquoi ?** Parce que l'IA fabrique la suite la plus vraisemblable, pas la suite vérifiée. Quand elle ne sait pas, elle peut « combler le vide ».

**Quand faut-il être encore plus prudent ?**

- Dates, chiffres, statistiques précises.
- Articles de loi, références juridiques.
- Sujets locaux peu documentés (petites entreprises, personnalités locales).
- Santé, argent, décisions importantes.

**Comment réduire les erreurs :**

1. Fournissez les documents et demandez de répondre **uniquement** à partir d'eux.
2. Autorisez le « je ne sais pas » : « Si tu n'es pas sûr, dis-le. »
3. Demandez les sources, puis **vérifiez-les vous-même**.
4. Comparez avec un site officiel ou un expert.

> **Exemple africain** Un étudiant demande la liste des articles d'une loi nationale. L'assistant lui donne des numéros d'articles avec assurance, mais certains sont faux. Le bon réflexe : consulter le texte officiel publié par les institutions du pays.

### 6.2 Les biais

L'IA apprend à partir de contenus créés par des humains. Elle en reproduit donc les **déséquilibres** :

- **Manque de représentation** : l'Afrique est parfois décrite comme un seul pays, avec des clichés.
- **Stéréotypes** : associer certains métiers à un genre.
- **Langues** : meilleurs résultats en anglais et en français qu'en wolof, en lingala ou en baoulé, par exemple.
- **Exemples décalés** : des noms, des prix ou des situations qui ne correspondent pas à votre réalité.

> **À retenir** Le biais n'est pas seulement un problème d'éthique : c'est aussi un problème de **qualité**. Une réponse qui ignore votre contexte est moins utile.

### 6.3 Autres limites

- **Date limite des connaissances** : l'assistant peut ne pas connaître les événements récents, sauf s'il utilise une recherche sur Internet.
- **Erreurs de logique et de calcul** sur des problèmes compliqués.
- **Manque de bon sens du terrain** : il peut proposer des solutions irréalistes (par exemple supposer qu'il y a toujours de l'électricité).

### 6.4 Arnaques et faux contenus

L'IA a aussi rendu plus faciles certaines manipulations :

| Risque | Exemple | Comment se protéger |
|---|---|---|
| **Faux messages très convaincants** | SMS ou e-mail imitant votre banque ou votre opérateur | Ne cliquez pas sur les liens, appelez le numéro officiel |
| **Voix clonée** | Faux appel d'un « proche » ou d'un « directeur » qui demande un virement urgent | Raccrochez et rappelez la personne sur son numéro habituel |
| **Fausses images ou vidéos (deepfakes)** | Faux discours d'une personnalité | Cherchez la même information dans plusieurs sources fiables |
| **Fausses offres d'emploi ou de bourses** | Demande de paiement pour « débloquer » un dossier | Ne payez jamais pour obtenir un emploi ou une bourse |

### 6.5 Les cinq questions de vérification

Avant d'utiliser une réponse, demandez-vous :

1. Puis-je la **vérifier** ailleurs ?
2. Quel est l'**enjeu** ? (Plus il est grand, plus il faut vérifier.)
3. Est-elle **adaptée à mon pays** et à ma situation ?
4. Y a-t-il des **oublis ou des préjugés** ?
5. Suis-je prêt(e) à **assumer** ce que je vais dire ou faire avec ?

> **À retenir** L'IA propose. **Vous décidez, et vous êtes responsable.**

### Résumé du chapitre 6

- L'IA peut se tromper avec assurance : ce sont les hallucinations.
- Elle peut reproduire des biais et mal connaître votre contexte.
- Les arnaques et faux contenus se multiplient : vérifiez toujours par un autre canal.
- La responsabilité finale vous appartient.

### Testez-vous

**Q1. Une hallucination est :**

a) Une réponse fausse présentée avec assurance ; b) Une panne de courant ; c) Un virus ; d) Un message d'erreur.

**Réponse : a.** L'IA peut inventer des faits qui semblent plausibles.

**Q2. Vous recevez un appel avec la voix de votre patron qui demande un virement urgent. Que faites-vous ?**

a) Vous virez tout de suite ; b) Vous raccrochez et rappelez sur son numéro habituel pour vérifier ; c) Vous donnez votre mot de passe ; d) Vous transférez l'appel à un ami.

**Réponse : b.** Une voix peut être clonée : vérifiez toujours par un second canal.

**Q3. Un assistant vous donne un chiffre précis sans source. Que faire ?**

a) L'utiliser tel quel ; b) Le vérifier dans une source officielle ; c) L'ignorer sans vérifier ; d) Le publier tout de suite.

**Réponse : b.** Les chiffres précis sont un point à risque.

## Chapitre 7 : Protéger mes données et ma vie privée

### Ce que vous allez apprendre

- Ce qu'est une donnée personnelle.
- Les réflexes de base pour rester en sécurité.
- Les repères juridiques en Afrique.

### 7.1 Qu'est-ce qu'une donnée personnelle ?

C'est toute information qui permet d'**identifier une personne** : nom, numéro de téléphone, adresse, photo, voix, numéro de compte, numéro de carte d'identité, informations de santé, localisation, etc.

Quand vous écrivez un texte à un assistant IA en ligne, ce texte **part vers les serveurs** de l'entreprise, souvent situés à l'étranger. Il faut donc réfléchir avant d'envoyer certaines informations.

### 7.2 Les trois réflexes

1. **Minimiser** : n'envoyez que ce qui est nécessaire.
2. **Anonymiser** : remplacez les noms par des codes. Exemple : « Client A » au lieu de « Koffi Kouassi ».
3. **Vérifier** : lisez les paramètres de confidentialité. Peut-on refuser que vos échanges servent à entraîner le modèle ?

**Exemple :**

| À éviter | Version plus sûre |
|---|---|
| « Koffi Kouassi, tél. 07 XX XX XX XX, doit 150 000 FCFA. Rédige-lui un rappel. » | « Rédige un rappel poli pour un client qui doit 150 000 FCFA. » Vous ajoutez le nom vous-même après. |

### 7.3 Ce qu'il ne faut jamais envoyer

- Mots de passe, codes PIN, codes de confirmation (OTP).
- Numéros de carte bancaire.
- Photos de pièces d'identité.
- Dossiers médicaux nominatifs.
- Documents confidentiels de votre employeur.
- Informations sur des enfants.

### 7.4 Quelques repères juridiques en Afrique

De nombreux pays africains ont des lois sur la protection des données personnelles. À titre d'exemples :

- **Côte d'Ivoire** : loi de 2013 sur la protection des données à caractère personnel (autorité : ARTCI).
- **Sénégal** : loi de 2008 (autorité : CDP).
- **Nigeria** : loi de 2023 (Nigeria Data Protection Act).
- **Kenya** : loi de 2019 (Data Protection Act).
- **Afrique du Sud** : loi POPIA.
- Au niveau africain : la **Convention de Malabo** (Union africaine, 2014) et une stratégie continentale sur l'IA adoptée en 2024.

> **Attention** Ces informations sont des repères généraux, pas des conseils juridiques. Les lois changent : cherchez le texte et l'autorité de votre pays pour connaître les règles actuelles.

### 7.5 Règles d'or pour votre sécurité numérique

- Utilisez des **mots de passe différents** pour chaque compte, et activez la **double authentification**.
- Méfiez-vous des **applications inconnues** qui promettent une « IA gratuite » mais demandent trop d'accès à votre téléphone.
- Ne partagez pas vos **codes reçus par SMS**.
- Mettez à jour vos applications.

### Résumé du chapitre 7

- Une donnée personnelle identifie une personne.
- Réflexes : minimiser, anonymiser, vérifier.
- Certaines informations ne doivent jamais être envoyées à un assistant.
- Des lois existent en Afrique ; renseignez-vous sur celle de votre pays.

### Testez-vous

**Q1. Quelle information est une donnée personnelle ?**

a) Un numéro de téléphone lié à un nom ; b) La météo du jour ; c) Une recette de cuisine ; d) Le nom d'une capitale.

**Réponse : a.** Elle permet d'identifier une personne.

**Q2. Comment anonymiser un texte avant de l'envoyer ?**

a) Remplacer les noms par « Client A » ou « Personne B » ; b) Ajouter des majuscules ; c) Le traduire ; d) L'envoyer deux fois.

**Réponse : a.** On retire ou remplace ce qui identifie les personnes.

**Q3. Que ne faut-il jamais partager avec un assistant ?**

a) Une question de grammaire ; b) Un code PIN ou un mot de passe ; c) Un titre d'exposé ; d) Un exercice de mathématiques.

**Réponse : b.** Ces données donnent accès à vos comptes.

## Chapitre 8 : L'IA et l'Afrique

### Ce que vous allez apprendre

- Les particularités du contexte africain.
- Pourquoi les langues africaines sont un enjeu majeur.
- Les opportunités et les obstacles.

### 8.1 Un continent, des réalités variées

L'Afrique compte 54 pays et des réalités très différentes : grandes villes connectées, villages isolés, économies variées. On ne peut donc pas généraliser. Toutefois, on retrouve souvent :

- Une **population jeune** et entreprenante.
- Un usage massif du **téléphone mobile**, souvent premier accès à Internet.
- Le **mobile money** (Orange Money, MTN MoMo, M-Pesa, Wave...) très répandu.
- **WhatsApp** comme outil central de communication, personnelle et professionnelle.
- Une **économie informelle** importante : petits commerces, artisanat, agriculture.
- Des **contraintes** : coût des données, coupures d'électricité, réseau instable.
- Le **multilinguisme** au quotidien : français ou anglais, plus une ou plusieurs langues locales.

> **À retenir** Une solution d'IA n'a de valeur que si elle est adaptée à ces réalités : utilisable sur mobile, économe en données, disponible dans les langues des gens, simple et abordable.

### 8.2 Le défi des langues

Le continent abrite plus de deux mille langues : swahili, hausa, yoruba, igbo, amharique, zoulou, wolof, lingala, bambara, dioula, baoulé, peul, arabe et beaucoup d'autres. Dans les villes, des parlers mixtes comme le nouchi (Côte d'Ivoire) ou le pidgin se développent aussi.

**Pourquoi les assistants IA sont-ils moins performants dans ces langues ?**

1. Beaucoup de langues sont surtout **orales** : peu de textes écrits sont disponibles sur Internet.
2. Il y a peu de **traductions et de données** de qualité pour entraîner les modèles.
3. Les **orthographes** varient parfois d'une région à l'autre.
4. Ce marché a longtemps été peu prioritaire pour les grandes entreprises.

**Conséquence :** des traductions approximatives, des réponses moins justes, et un risque d'exclure des millions de personnes des bénéfices de l'IA, surtout celles qui n'ont pas eu accès à l'école dans une langue internationale.

**La voix, clé de l'inclusion.** Pouvoir parler à un assistant dans sa langue et l'entendre répondre à voix haute est particulièrement précieux pour les personnes peu alphabétisées.

### 8.3 Des initiatives qui avancent

De nombreuses initiatives travaillent à corriger ce retard. À titre d'exemples (vérifiez leur situation actuelle) :

- **Masakhane** : communauté africaine qui construit des ressources pour les langues africaines.
- **Deep Learning Indaba** : grand rassemblement annuel de la communauté africaine de l'IA.
- **Lelapa AI** (Afrique du Sud) : entreprise qui développe des outils pour des langues africaines.
- **Jacaranda Health** (Kenya) : santé maternelle, avec des messages en swahili.
- **Mozilla Common Voice** : projet où des volontaires enregistrent leur voix pour créer des données ouvertes.
- Des **universités, laboratoires et hubs d'innovation** dans de nombreux pays.

> **Exemple africain** Vous pouvez contribuer : enregistrer des phrases dans votre langue pour un projet de données ouvertes, relire des traductions, signaler des erreurs, rejoindre une communauté locale.

### 8.4 Où l'IA peut aider

| Domaine | Exemples d'usage |
|---|---|
| **Agriculture** | Conseils sur les cultures, aide à comprendre un bulletin météo, rédaction d'un dossier de financement pour une coopérative |
| **Santé** | Messages de prévention en langues locales, aide à la rédaction de rapports (jamais de diagnostic par l'IA seule) |
| **Éducation** | Tuteur personnel, préparation de cours, exercices, explications autrement |
| **Commerce et finance** | Messages clients, plan d'affaires, suivi simple des comptes |
| **Administration** | Information sur les démarches, traduction, résumés de textes |
| **Création et médias** | Rédaction, sous-titrage, visuels, musique |
| **Emploi** | CV, lettres de motivation, préparation aux entretiens |

### 8.5 Les obstacles

- **Coût** des données et des abonnements en devises étrangères.
- **Électricité et réseau** parfois instables.
- **Manque de formations** accessibles et de données locales.
- **Dépendance** vis-à-vis de technologies et de serveurs situés hors du continent.
- **Cadres juridiques** encore en construction dans certains pays.
- **Craintes légitimes** : emploi, vie privée, désinformation.

### 8.6 L'Afrique, utilisatrice mais aussi créatrice

L'enjeu est que l'Afrique ne soit pas seulement **consommatrice** de technologies conçues ailleurs, mais aussi **créatrice** : données dans ses langues, start-ups, chercheurs, lois adaptées. Chaque personne formée à l'IA contribue à cet objectif.

### Résumé du chapitre 8

- Le contexte africain est marqué par le mobile, le multilinguisme, l'économie informelle et des contraintes d'infrastructure.
- Le manque de données dans les langues africaines limite la qualité des assistants ; des communautés travaillent à y remédier.
- Les opportunités sont nombreuses, mais les précautions restent nécessaires.

### Testez-vous

**Q1. Pourquoi les assistants IA sont-ils souvent moins bons dans certaines langues africaines ?**

a) Elles sont trop compliquées ; b) Il existe peu de textes et de données numériques pour les entraîner ; c) Elles sont interdites ; d) Elles n'ont pas de locuteurs.

**Réponse : b.** Le manque de données de qualité est la cause principale.

**Q2. Quel canal est très utilisé en Afrique pour toucher les gens avec de l'IA ?**

a) Le fax ; b) WhatsApp ; c) Le télégramme ; d) Le minitel.

**Réponse : b.** WhatsApp est très répandu, ce qui facilite l'accès.

**Q3. Comment pouvez-vous contribuer à une IA plus inclusive ?**

a) En ne faisant rien ; b) En enregistrant sa voix ou en relisant des traductions pour des projets ouverts ; c) En supprimant tous les outils ; d) En copiant des textes protégés.

**Réponse : b.** La contribution communautaire aide à créer des données de qualité.

## Chapitre 9 : L'IA dans mon quotidien : cas pratiques

### Ce que vous allez apprendre

- Voir l'IA à l'œuvre dans des situations réelles.
- Réutiliser des prompts comme modèles.

> **Astuce** Copiez ces modèles et remplacez les éléments entre crochets par vos propres informations. Vérifiez toujours les chiffres et les faits.

### Cas 1 : La commerçante en ligne

**Situation.** Aminata vend des pagnes sur WhatsApp et Instagram, à Abidjan. Elle veut répondre plus vite à ses clientes et publier régulièrement.

```
Tu es assistante de vente pour une boutique de pagnes à Abidjan.
Ton ton est chaleureux et bref (3 phrases maximum).
Paiement : espèces, Orange Money, Wave, MTN MoMo.
Livraison : Abidjan 2 000 FCFA (48 h), intérieur 4 000 FCFA.
Rédige une réponse à ce message d'une cliente : "[message]".
```

**À vérifier.** Prix, délais promis, orthographe.

### Cas 2 : L'enseignante

**Situation.** Mme Diop, à Dakar, a 60 élèves par classe et veut proposer des exercices adaptés.

```
Tu es un pédagogue expérimenté en [matière], niveau [classe],
programme [pays].
Prépare 5 exercices de difficulté croissante sur [notion], avec
un exemple de la vie quotidienne au Sénégal, puis le corrigé.
```

**À vérifier.** Exactitude des contenus et conformité au programme officiel.

### Cas 3 : Le producteur ou la coopérative agricole

**Situation.** Une coopérative de mangues, au nord de la Côte d'Ivoire, veut expliquer à ses membres une nouvelle méthode de séchage.

```
Explique cette méthode de séchage de mangues à des producteurs
peu alphabétisés : phrases courtes, 5 lignes maximum.
Puis écris un script de 30 secondes pour un message vocal WhatsApp.
Méthode : [description]
```

**À vérifier.** Faire relire dans la langue locale par un membre de confiance.

### Cas 4 : L'agent de santé communautaire

**Situation.** Il veut préparer un message de prévention sur le lavage des mains.

```
Rédige un message de 6 phrases simples sur le lavage des mains
pour une communauté d'Afrique de l'Ouest. Niveau de lecture :
primaire. Ne donne aucun conseil de traitement médical individuel.
Termine par : "Pour plus d'informations, consultez votre centre
de santé."
```

**À vérifier.** Contenu validé par un professionnel de santé. Aucune donnée de patient dans l'outil.

### Cas 5 : L'étudiant

**Situation.** Il veut mieux comprendre un cours difficile.

```
Explique-moi [notion] comme à un débutant, avec un exemple de la
vie quotidienne en [pays]. Puis pose-moi 5 questions, une à la
fois, pour vérifier que j'ai compris.
```

**À vérifier.** Comparer avec son cours et poser des questions à l'enseignant. L'IA sert à comprendre, pas à copier.

### Cas 6 : Le demandeur d'emploi

**Situation.** Elle prépare un entretien pour un poste de comptable à Douala.

```
Agis comme un recruteur pour un poste de comptable dans une PME
à Douala. Pose-moi une question à la fois, attends ma réponse, puis
donne-moi un retour bref et un conseil d'amélioration.
```

**À vérifier.** Adapter les conseils à la culture de l'entreprise visée.

### Cas 7 : L'agent administratif

**Situation.** Il doit rédiger un compte rendu de réunion.

```
Voici mes notes brutes : [notes].
Rédige un compte rendu avec : participants, décisions, actions
(responsable et date limite). Utilise un tableau pour les actions.
N'ajoute aucune information absente des notes.
```

**À vérifier.** Les informations sensibles sur des personnes doivent être anonymisées ou ne pas être envoyées.

### Résumé du chapitre 9

- L'IA peut aider dans presque tous les métiers, si la demande est claire.
- Vérification, confidentialité et relecture locale restent nécessaires.

### Testez-vous

**Q1. Dans le cas d'une coopérative agricole, quelle précaution est importante ?**

a) Faire relire le message dans la langue locale ; b) Le diffuser sans le lire ; c) Le rendre plus compliqué ; d) L'écrire en majuscules.

**Réponse : a.** Cela évite les erreurs de compréhension.

**Q2. Pour un message de santé, que fait l'IA ?**

a) Elle remplace le médecin ; b) Elle aide à rédiger un message qui sera validé par un professionnel ; c) Elle pose un diagnostic ; d) Elle prescrit un médicament.

**Réponse : b.** L'IA aide à rédiger ; un professionnel valide.

**Q3. Comment l'étudiant doit-il utiliser l'IA ?**

a) Pour éviter d'étudier ; b) Pour mieux comprendre et s'entraîner ; c) Pour tricher ; d) Pour copier les réponses d'examen.

**Réponse : b.** L'IA est un outil d'apprentissage, pas de substitution.

## Chapitre 10 : Mon plan d'action de 30 jours

### Ce que vous allez apprendre

- Construire une habitude d'utilisation.
- Réaliser un mini-projet personnel.
- Continuer à progresser.

### 10.1 Plan sur 30 jours

| Période | Objectif | Activités |
|---|---|---|
| **Semaine 1** | Découvrir | Installer ou ouvrir un assistant, faire 10 conversations simples, tester la méthode R-C-T-F |
| **Semaine 2** | Pratiquer | Utiliser l'IA pour 3 tâches réelles de votre travail ou de vos études, améliorer chaque résultat en 3 échanges |
| **Semaine 3** | Vérifier | Vérifier 10 informations données par l'IA, tester en langue locale, appliquer les réflexes de sécurité |
| **Semaine 4** | Créer | Réaliser votre mini-projet et le présenter à un collègue, un ami ou un professeur |

### 10.2 Mon mini-projet

**Consigne.** Choisissez **un problème réel** de votre quotidien ou de votre communauté et utilisez l'IA pour y répondre.

**Idées :**

- Préparer un kit de 10 messages WhatsApp pour votre activité.
- Créer une fiche d'aide pour vos élèves ou vos clients.
- Rédiger un dossier de présentation de votre projet.
- Construire un planning d'apprentissage personnel.

**Ce que votre mini-projet doit contenir :**

1. Le **problème** et les personnes concernées.
2. Vos **prompts** (au moins trois) et leur évolution.
3. Ce que vous avez **vérifié ou corrigé** dans les réponses.
4. Les **précautions** prises pour vos données.
5. Ce que vous avez **appris**.

### 10.3 Ma charte personnelle

Recopiez et complétez :

```
MA CHARTE PERSONNELLE D'USAGE DE L'IA
1. J'utilise l'IA pour : ...................................
2. Je ne partage jamais : ..................................
3. Je vérifie toujours : ..................................
4. Je fais relire par un humain : ..........................
5. Je reste responsable de ce que je publie ou envoie.
```

### 10.4 Pour continuer

- **Pratiquez** un peu chaque jour, même 15 minutes.
- **Apprenez avec d'autres** : club, groupe WhatsApp, atelier de votre communauté.
- **Testez** les nouveautés sur des cas réels.
- **Partagez** ce que vous savez : enseigner est la meilleure façon d'apprendre.
- **Passez au niveau suivant** : le livre pour niveau intermédiaire approfondit le fonctionnement des modèles, le RAG, les agents, l'éthique et l'adoption en organisation.

### 10.5 Un mot pour conclure

L'IA générative n'est ni magique, ni effrayante. C'est un outil puissant mais imparfait, qui reflète les données et les choix de ceux qui le construisent. Utilisée avec esprit critique, elle peut vous faire gagner du temps, vous aider à apprendre et à créer. L'Afrique a besoin de personnes formées, curieuses et exigeantes, prêtes à utiliser cette technologie et à contribuer à sa construction. Vous en faites désormais partie.

### Résumé du chapitre 10

- Un plan de 30 jours aide à ancrer les bonnes habitudes.
- Un mini-projet réel consolide les acquis.
- Une charte personnelle protège vos données et votre jugement.

### Testez-vous

**Q1. Quel est le meilleur type de mini-projet ?**

a) Un problème réel de votre quotidien ; b) Un sujet sans rapport avec vous ; c) Un projet copié d'Internet ; d) Un projet impossible à vérifier.

**Réponse : a.** Un problème réel motive et permet d'évaluer l'utilité.

**Q2. Que faut-il faire régulièrement pour progresser ?**

a) Pratiquer un peu chaque jour ; b) Tout apprendre en une nuit ; c) Éviter toute pratique ; d) Ne lire aucune information.

**Réponse : a.** La régularité vaut mieux que les longues sessions rares.

**Q3. Qui reste responsable d'un contenu produit avec l'aide de l'IA ?**

a) L'IA ; b) L'entreprise qui l'a conçue ; c) La personne qui l'utilise et le diffuse ; d) Personne.

**Réponse : c.** L'IA propose, l'humain décide et assume.

## Annexe A : Glossaire pour débutants

| Terme | Explication simple |
|---|---|
| **Assistant IA** | Programme avec lequel on discute pour obtenir de l'aide |
| **Biais** | Préjugé ou déséquilibre reproduit par l'IA à partir de ses données |
| **Deepfake** | Image, voix ou vidéo truquée par IA |
| **Donnée personnelle** | Information qui permet d'identifier quelqu'un |
| **Hallucination** | Réponse fausse présentée avec assurance |
| **IA générative** | IA qui crée du contenu nouveau |
| **LLM** | Grand modèle de langage : le moteur des assistants de texte |
| **Machine learning** | Apprentissage d'une machine à partir d'exemples |
| **Modèle** | Le « cerveau » de l'IA, fruit de l'entraînement |
| **Modèle ouvert** | Modèle qu'on peut télécharger et installer soi-même |
| **Prompt** | Instruction que vous donnez à l'IA |
| **R-C-T-F** | Méthode : Rôle, Contexte, Tâche, Format |
| **Température** | Réglage du degré de hasard dans les réponses |
| **Token** | Petit morceau de texte traité par l'IA |

## Annexe B : 8 prompts prêts à l'emploi

**1. Résumer un texte**

```
Résume ce texte en 5 points clés, avec des mots simples.
N'ajoute rien qui n'est pas dans le texte.
Texte : [texte]
```

**2. Écrire un message professionnel**

```
Rédige un message [formel / amical] pour [destinataire] afin de
[objectif]. Longueur : [x] lignes. Termine par une demande claire.
```

**3. Expliquer simplement**

```
Explique [sujet] à un débutant avec un exemple de la vie quotidienne
en [pays]. Utilise des phrases courtes.
```

**4. Préparer un entretien**

```
Agis comme recruteur pour un poste de [poste]. Pose-moi une question
à la fois et donne-moi un retour après chaque réponse.
```

**5. Créer un plan**

```
Aide-moi à créer un plan de [durée] pour [objectif]. Budget : [montant].
Format : tableau avec étape, action, durée, coût.
```

**6. Traduire et vérifier**

```
Traduis ce texte en [langue]. Puis retraduis ta version en français
et indique les différences de sens. Signale les mots incertains.
```

**7. Vérifier une réponse**

```
Relis ta réponse. Dis-moi ce dont tu es sûr, ce qu'il faut vérifier
et ce que tu as peut-être inventé.
```

**8. Améliorer mon texte**

```
Relis mon texte. Liste les erreurs, les phrases peu claires et les
points à améliorer, puis propose une version corrigée.
Texte : [texte]
```

## Annexe C : Fiche mémo

**Les 10 règles d'or du débutant**

1. L'IA **devine la suite**, elle ne **sait** pas : vérifiez.
2. Un bon prompt suit **R-C-T-F** : Rôle, Contexte, Tâche, Format.
3. Donnez votre **contexte local** : pays, monnaie, langue, contraintes.
4. Le premier résultat est un **brouillon** : améliorez-le.
5. **Ne partagez jamais** mots de passe, codes, pièces d'identité, données confidentielles.
6. **Anonymisez** avant d'envoyer un texte sensible.
7. Faites **relire** les textes en langue locale sur les sujets importants.
8. Méfiez-vous des **faux messages, fausses voix et fausses vidéos**.
9. **Vous décidez, vous êtes responsable.**
10. **Pratiquez** un peu chaque jour et partagez ce que vous apprenez.
